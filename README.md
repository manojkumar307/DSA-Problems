# DSA-Problems

A collection of Data Structures and Algorithms (DSA) problems solved in Java.

This repository contains practice problems, assignment solutions, and algorithm implementations covering various DSA concepts. The goal is to improve problem-solving skills, code efficiency, and understanding of algorithmic techniques.

## Example Problems

### EventBudgetSplit
Finds a split point in an array where the sum of elements on the left equals the sum of elements on the right.

### BalancedMultiplicationCheckpoints
Counts positions where the product of elements to the left equals the product of elements to the right.

### DeliverWalletBalance
finds the highest balanced reached for the day.

### StoreVisitorMilestones
finds the cumulative customers visited the store for the each hour and has it crossed the limit set for the day.
